# Salva Dental Studio — Cinematic Website

Responsive dental website inspired by the uploaded visual references: pale blue surfaces, cobalt-blue panels, oversized typography, layered clinical photography and cinematic motion.

Included: SEO metadata and Dentist structured data; staged hero reveal; scroll-triggered section reveals; decorative Three.js hero visual; interactive doctor carousel; patient-review controls; FAQ accordion; appointment request form; reduced-motion support.

Open `index.html` in a modern browser. No build step is required. Google Fonts, Unsplash images and Three.js require an internet connection.

Before publishing, replace the example domain, phone, address, email, doctor profiles, opening hours and illustrative metrics/testimonials. Connect the form to a secure booking system before collecting patient information. Verify clinical wording and image licensing.
